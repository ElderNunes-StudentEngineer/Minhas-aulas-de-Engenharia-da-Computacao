# 📚 Minhas Aulas de Engenharia da Computação

Repositório com materiais, exercícios e códigos desenvolvidos durante minha graduação em Engenharia da Computação.

## 🎯 Objetivo

Organizar e documentar meu aprendizado ao longo do curso, reunindo conteúdos de cada disciplina.

## 📂 Estrutura do Repositório

As pastas estão organizadas por disciplina:

* 📁 Arquitetura
* 📁 ASL
* 📁 Desenho Técnico
* 📁 ED1 (Estrutura de Dados 1)
* 📁 ED1_DP
* 📁 ED2
* 📁 POO (Programação Orientada a Objetos)
* 📁 SO (Sistemas Operacionais)
* 📁 Programação 1
* 📁 Programação 2
* 📁 qtCreator

## 🚀 Tecnologias Utilizadas

* C
* C++
* Python
* Makefile
* Assembly (básico)

## ⚠️ Observações

* Este repositório é para fins educacionais
* Os códigos podem não estar otimizados (foco no aprendizado)
* Algumas soluções podem não ser as melhores práticas
